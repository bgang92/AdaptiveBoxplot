This package implements the FWER and FDR boxplots descirbed in Gang, Bowen, Hongmei Lin, and Tiejun Tong. "Unifying boxplots: a multiple testing perspective." arXiv preprint arXiv:2510.20259 (2025).
The package can also be download from CRAN using thge following code:
install.packages('AdaptiveBoxplot')
